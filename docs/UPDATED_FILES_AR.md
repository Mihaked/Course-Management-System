## ✅ الملفات المطلوبة للتحديث (نسخ/استبدال)

لو عندك نسخة قديمة من المشروع وعايز تضيف التعديلات الجديدة (تسجيل الطلاب + اختيار المستوى/الترم)، اتبع القائمة دي بالترتيب.

### 1) ملفات جديدة لازم تضيفها
انسخ الملفات دي كاملة داخل نفس فولدر المشروع:
- `register.php`
- `register_process.php`
- `student_dashboard.php`

### 2) ملفات لازم تستبدلها بالنسخة المعدلة
استبدل الملفات دي من النسخة الجديدة داخل النسخة القديمة:
- `index.php` (إضافة لينك التسجيل وتحويل الطالب للـ dashboard)
- `add_course.php` (إضافة اختيار Level / Semester)
- `add_course_process.php` (حفظ level/semester)
- `courses.php` (عرض level/semester)
- `edit_course.php` (تعديل level/semester)
- `view_course.php` (تقييد الوصول حسب مستوى الطالب)
- `includes/header.php` (روابط التنقل حسب الدور)
- `includes/db_connection.php` (قاعدة البيانات: `cms_db1`)

### 3) قاعدة البيانات
استورد ملف `cms_db.sql` من النسخة الجديدة على قاعدة بيانات باسم:
```
cms_db1
```
لو عندك بيانات مهمة وعايز تحتفظ بها:
- أضف يدويًا الأعمدة `level` و `semester` في جدول `courses`.
- أضف جدول `student_profiles` الجديد.

---
لو محتاج أي ملف بالتفصيل كامل (كوبي‑بيست)، قولي اسم الملف وأنا أكتبه لك كامل.
